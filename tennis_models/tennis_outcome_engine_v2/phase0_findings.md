# Tennis Outcome Engine V2 — Phase0 forensic findings

Evidence grade: **RETROSPECTIVE_BURNED** for every number below (VAL 2020–2022 and HOLDOUT 2023–2024 were consumed by the incumbent gate decisions). 2025 is SEALED (never read) and 2026 is EXPOSED (never read).
Protocol `protocol.json` was committed first (`99dd427`), then code and tests, then these results. ATP and WTA are never pooled. Nothing is promoted; no production file is touched; no betting-market quantity is an input anywhere.
All figures are regenerated by `tennis_v2_phase0_audit.py` and reproduced numerically by the dedicated workflow.

## 0. Disclosures (read first)

1. The driver was run locally once before the code commit to debug it; those outputs were discarded. A second code-only commit then added **descriptive postgame information ceilings** for total games *after I had seen that best-of alone nearly matches the incumbent*; a third added the architecture status to the verdict table. None changes a baseline constant, verdict rule or population. Results in this directory come from the final committed code and were produced twice with identical hashes.
2. The frozen **competent-human baseline for total games is biased high** (+1.0 game ATP, +0.9 WTA): the expected-set count from the iid race model overstates real set counts. The protocol froze its definition before results, so it was **not rescue-tuned**. It is reported but it does not define any verdict; the strongest simple baseline does. Read it as "the specified human construction is mediocre", not as the best a human could do.
3. ATP numbers reproduce the committed gate reports **exactly** (8/8 comparisons). The four WTA HOLDOUT comparisons differ (n 4553 vs 4464 for total games/spread, 5041 vs 4946 moneyline, 4841 vs 4750 set betting); VAL matches exactly. The WTA gate DB was built from the mutable TML website, which has since changed; the pinned hashes cannot reproduce it. WTA conclusions therefore rest on the pinned files, not on the committed WTA reports.
4. ESPN data was not retrieved. Identity/surface replays use the logged picks and TML 2015–2024 only, so they are lower bounds on live behaviour.
5. Oracle ceilings use realised postgame facts. They size headroom; they are not forecasts and cannot be shipped.

## 1. The incumbent system (what is actually running)

* Six champion gates (moneyline, total games, games spread, set betting, aces, double faults) on a hash-unpinned-at-the-time TML database, split DEV 2015–19 / VAL 2020–22 / HOLDOUT 2023–24. Production serves **moneyline, total games and set betting**. The moneyline is served but **not graded** in `tennis_record.json` (only total games and set betting are). Spread, aces and double faults failed their gates and are not served.
* Every model is a hand-set smoother: Elo (K = 250/(n+5)^0.4, overall + surface blend), recency-weighted games-per-set × expected sets, Elo → per-set probability → iid race-to-N. No parameter is fitted beyond constants.
* `phase0_current_engine_audit.json` holds per-market formulas, minimum history, the market-token scan of the production code (execution-only inside the serving builder; no gate reads a betting quantity) and the pick-log audit: 704 picks, 44.9% unagraded, 131 total-games rows whose "line" is the model's own projection, no engine version, no input snapshot, no hash chain, mutable file, and science fields mixed with line/price fields.

## 4. Total games (priority one) — what limits it

* Identical-row baselines (HOLDOUT MAE, n=4898 ATP / 4456 WTA): prior-3 6.85/5.15, prior-5 6.80/5.04, prior-10 6.73/4.97, EWMA 6.65/5.08, p1 tendency 6.89/5.07, p2 tendency 6.84/5.05, surface-fit 5.55/4.94, best-of-fit 5.56/4.93, **Elo-mismatch-fit 5.51/4.90**, incumbent 5.69/5.09, human 5.68/5.06.
* Segments (HOLDOUT MAE, ATP): best-of-3 5.05 (mismatch) vs 5.22 (incumbent); best-of-5 7.60 vs 7.87; grass 5.98 vs 6.26; large favourite (≥0.75) 5.52 vs 5.83. The incumbent loses in every segment. Miss rates (ATP HOLDOUT): >10 games 13.7% (incumbent) vs 11.5% (Elo-mismatch), >15 games 2.7% vs 1.9%; WTA 9.3% vs 6.2% and 0.6% vs 0.4%.
* **Descriptive ceilings** (in-sample, postgame; ATP HOLDOUT, MAE vs best-of-only 5.59): pre-match Elo mismatch → 5.53 (−1.1%); knowing the realised **set count** → 2.66 (−52%); knowing the realised **serve-point win rates** → 3.87 (−31%); both → 1.96 (−65%). WTA: 4.94 → mismatch 4.89 (−0.9%), set count 2.48 (−50%), serve 3.08 (−38%), both 1.74 (−65%).
  Reading: total games is overwhelmingly a *set-count / competitiveness* problem, and pre-match strength explains about 1% of it. Serve-point win is moderately predictable out of time (R² improvement over the tour mean 9.8% ATP, 4.4% WTA), so a serve/return engine could capture only a small share of the 31–38% serve-information ceiling. A realistic total-games improvement over the best simple baseline is therefore small and would need to clear the 2.0% SURVIVES bar.
* Catastrophic misses (|error| > 10 games): 2,451 receipts; 2,094 in the >10 tier and 357 in >15. Cause flags are overlapping and descriptive: BEST_OF_5 685, TIEBREAK_HEAVY 576, CLOSE_MATCHUP_LONG 573, HEAVY_FAVORITE_BLOWOUT 261, SET_COUNT_SURPRISE 261, ORDER_LEAKAGE_EXPOSED 1, **UNATTRIBUTED 899 (37%)**.

## 5. Serve/return feasibility (audit only; nothing built)

Both tours **DATA_SUFFICIENT**: completed-match serve coverage ATP 96.7% / WTA 95.1% (HOLDOUT), identity violation rate 0.014% / 0.030%, return points derivable from the opponent row, out-of-time serve-point-win R² improvement 9.8% / 4.4% (own history + opponent return), closed-form hold probability matches observed hold on average (ATP 0.803 vs 0.795; WTA 0.664 vs 0.654) with the usual per-match noise (MAE 0.12 / 0.16). ## 7. Recommendation (evidence only)

* **Phase1 should target MONEYLINE** (match-win probability) as the first market, built as the strength/serve/return state layer that every other market is derived from. Evidence: it is the only market where a transparent human construction beats the incumbent with a clear interval in 3 of 4 tour-periods (and is never worse); it has the largest clean sample and an unambiguous label; the incumbent is measurably overconfident; and the total-games oracle shows competitiveness (set count) is the dominant residual of the derived markets, so a better coherent win probability is the prerequisite for set score, spread and total games.
* **Do not start with total games.** Despite being the stated priority, the incumbent has no demonstrated edge over a best-of constant, pre-match strength adds ~1%, and the reachable serve information is thin. It becomes a Phase2 *derived* market only if the Phase1 layer produces a coherent set distribution that beats Elo-mismatch-fit by ≥ 2.0% with the interval below 0 on the sealed 2025 season.
* Games spread has the largest easy gain (a trivial Elo-bucket baseline is 14–16% better than the incumbent) but is not a served or priced market in the current product; set score should be rebuilt on the same layer (not iid sets).
* Aces/double faults: not recommended; error is dominated by per-match rate noise.
* Required before any V2 forecast: canonical ordering, identity classes (forbid non-EXACT/NORMALIZED_EXACT), surface classes (forbid HARD_FALLBACK for non-hard-court-certain events or carry the class), RAW and CLEAN ledgers, and the V2 forward ledger in `phase0_current_engine_audit.json` (`v2_forward_ledger_design`).

## 8. What this does *not* show

Nothing here is an out-of-sample estimate of a future edge. All baselines use constants estimated on DEV only and are evaluated on periods already consumed by the incumbent's own decisions. The sealed 2025 season is the only untouched evidence and it is reserved for one Phase1 confirmation pass.
